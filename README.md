# GreePlus-Global-OHOS

给纯血鸿蒙（HarmonyOS NEXT）写的一个海外版格力空调（Gree+）第三方客户端。自己日常用，主打界面干净、操作顺手、带桌面卡片。

## 主要功能

- **家里外头都能控**：在家连 Wi-Fi 走本地直连，响应快；出门切流量自动走海外云端远控。
- **常用功能齐全**：开关机、调温、模式、风速、上下/左右各 5 档定格风向，以及灯光、睡眠、强劲、静音等附加功能。
- **桌面万能卡片**：支持 `2×2` 和 `2×4` 桌面卡片，不用打开 App 就能直接开关机、调温、切模式/风速/摆风，也支持在卡片上直接切换不同的空调。
- **干净无广告**：尽量贴近原生鸿蒙的交互和视觉，去掉了多余的弹窗和杂项。

## 使用小提示

- **仅支持海外版 Gree+ 账号**：目前适配的是海外版格力+ 体系，国内版“格力+”未做测试。
- **关于账号互踢**：格力+ 官方限制同一个账号只能在一台设备上在线。如果官方 App 和本客户端登同一个号，会互相顶下线。最省心的办法是在官方 Gree+ App 里用「家庭共享」邀请一个副邮箱账号，专门给这边登录，互不影响。

## 自行编译

1. 使用 DevEco Studio 打开本项目（`entry/` 为主模块）。
2. 在工程中配置好自己的鸿蒙调试/发布签名（`build-profile.json5` 默认未包含个人签名配置）。
3. 编译安装到真机即可（支持真机体验完整局域网、云端与桌面卡片功能）。
